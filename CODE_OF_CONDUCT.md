# Community guidelines

Keep ClipThat's issues, discussions, and pull requests useful and welcoming:

- Be respectful of people with different backgrounds and levels of experience.
- Critique the work with concrete examples. Avoid personal attacks, harassment,
  discriminatory language, threats, and repeated unwanted contact.
- Stay on topic and avoid spam. Give others room to disagree and correct mistakes.
- Respect privacy. Do not post someone else's capture, recording, personal information,
  or credentials without permission. Prefer synthetic examples.

For a problem in a GitHub conversation, use GitHub's **Report content** option where available,
or flag the relevant public comment to the repository owner, [@XtraSaltyDev](https://github.com/XtraSaltyDev),
without repeating abusive or private material. If reporting itself requires private information,
use GitHub's reporting tools rather than a public issue. Maintainers may moderate conversations
and contributions to keep the project usable. No separate private conduct-reporting channel or
response deadline is promised here.

For software vulnerabilities, follow [SECURITY.md](SECURITY.md).
