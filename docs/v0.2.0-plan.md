# ClipThat v0.2.0

## Scope

The release improves finding and organizing an existing local Library. It builds on the
capture, editor, comparison and Trash workflows shipped through v0.1.25.

1. Save named collections containing search, kind, favourites, tag and sort criteria.
   Reopen, rename and remove them from the Library. New matching captures appear automatically.
   Keep collection storage in main with validated IPC, atomic writes and backup recovery.
2. Apply tags and favourites to a selection in one Library transaction. Preserve each item's
   other tags, editable work, OCR cache, dates and export links. Reject stale selections and
   tag-limit violations before committing. Report persistence failures without partial changes.
3. Extend Library search with title, tag, text, type, favourite and date fields. Preserve
   ordinary words, quoted phrases and exclusions. Use confidence-qualified text for OCR search.
